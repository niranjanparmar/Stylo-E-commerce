# 🛍️ Stylo E-commerce

**Stylo E-commerce** is a modern online shopping platform that offers a variety of fashion and lifestyle products. Users can browse products, add items to their cart, and securely place orders with an easy-to-use interface.

---

## 🌐 Live Demo

🚀 **Visit the website:**
https://stylo-e-commerce.onrender.com

---

## 🚀 Features

* 🏠 Browse homepage with product listings
* 🛒 Add products to cart
* 🔍 View product details
* 👤 User authentication (Sign up / Login)
* 💳 Online payment support
* 📦 Order review and checkout
* 📱 Fully responsive design (Mobile + Desktop)

---

## 💻 Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python (Flask)
* **Database:** MongoDB
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

1️⃣ Clone the repository

```
git clone https://github.com/your-username/stylo-e-commerce.git
cd stylo-e-commerce
```

2️⃣ Create virtual environment

```
python -m venv .venv
```

3️⃣ Activate virtual environment

* Windows:

```
.venv\Scripts\activate
```

4️⃣ Install dependencies

```
pip install -r requirements.txt
```

5️⃣ Run the application

```
python main.py
```

6️⃣ Open in browser

```
http://127.0.0.1:5000
```
